Data Sintetis RADAR

Seluruh data di prototype ini dibuat oleh skrip, bukan diambil dari data peserta JKN atau perusahaan mana pun. Generator lebih dulu membuat kenyataan (pekerja dan upah riil) untuk 1.200 badan usaha fiktif, lalu membuat laporan ke JKN yang pada __FRAUD_PCT__% usaha sengaja dimanipulasi dengan empat modus. Sumber eksternal disimulasikan dari kenyataan dengan sedikit gangguan acak. Cara data diolah sampai menjadi skor bisa diikuti di Jejak Skor.

Data sintetis · versi dan waktu pembaruan tersedia di bawah

Template data sampel

Siapkan data untuk RADAR

Template Excel berisi 8 sheet data kosong dan 1 sheet petunjuk, lengkap dengan definisi 55 kolom, contoh format, pilihan isian, dan relasi antar-tabel.

Unduh Template Isian Data RADAR (.xlsx)

Isi mulai baris 2. Kunci jawaban hanya diisi jika ada hasil pemeriksaan tepercaya. Belum tersedia impor Excel otomatis; ekspor setiap sheet data ke CSV UTF-8 dan validasi sebelum diproses. Sampel tanpa label atau sumber eksternal memerlukan penyesuaian pipeline terlebih dahulu.

Pembaruan data

Jalankan ulang data dan scoring

Tanggal generate tersedia setelah pembaruan

Simulasikan snapshot terbaru, atau hitung ulang skor setelah file CSV di folder data/csv diperbarui. Proses mencakup indikator, aturan, Isolation Forest, evaluasi, dan halaman situs.

Tanggal generate menjadi pengunci simulasi. Tanggal yang berbeda menghasilkan dataset sintetis baru, bukan tambahan transaksi pada perusahaan yang sama. Periode observasi tetap Oktober 2025–September 2026. Untuk hitung ulang CSV, tanggal pilihan tidak mengubah datanya; tabel kunci jawaban harus sesuai agar evaluasi bermakna. Nilai kebenaran upah dan TK aktif di Jejak Skor tidak tersedia pada proses hitung ulang CSV.

Hasil lama dicadangkan dan hasil baru diaktifkan setelah proses berhasil. Excel adalah arsip awal dan tidak ikut diperbarui. Action plan tetap tersimpan; pada snapshot baru, ID perusahaan yang sama dapat merujuk profil sintetis yang berbeda.

Membangun ulang

  
Data, skor, dan ketiga halaman situs ini dibangun ulang dengan satu perintah dari folder repositori:

  
pip install -r model/requirements.txt
python model/build_web.py

  
Skrip: model/generate_data_sintetis.py (data), model/radar_model.py (indikator, aturan, Isolation Forest, skor), model/build_web.py (situs).
